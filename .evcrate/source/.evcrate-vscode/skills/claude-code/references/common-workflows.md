# Common Claude Code Workflows

## Feature Implementation

**Plan first approach:**
```bash
/cmd-plan implement payment integration with Stripe
# Review plan, then proceed with implementation
/cmd-cook implement payment integration with Stripe
```

**Direct implementation:**
```bash
/cmd-cook implement user authentication with JWT
/cmd-cook-auto add dark mode toggle to settings
```

## Bug Fixing

**Quick fixes:**
```bash
/cmd-fix-fast login button not working
/cmd-fix-types  # Fix TypeScript errors
```

**Complex debugging:**
```bash
/cmd-debug API returns 500 errors intermittently
/cmd-fix-hard authentication flow breaks after password reset
```

**Test-driven fixes:**
```bash
/cmd-fix-test user service tests failing
/cmd-test  # Run full test suite
```

**CI/CD failures:**
```bash
/cmd-fix-ci https://github.com/org/repo/actions/runs/12345
```

## Code Review & Testing

```bash
# Review recent changes
claude "review my latest commit"
claude "analyze the changes in PR #42"

/cmd-fix-test payment tests failing
```
